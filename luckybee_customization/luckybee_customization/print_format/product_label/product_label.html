{#- Phase 2 section 4 - product label, 50mm x 25mm. Layout follows the design the client supplied: the name runs across the top, the price is the hero in the middle with a SALE badge beside it, and MRP and SAVINGS sit as a labelled pair along the bottom. The barcode column moved to the right-hand edge, bars and readable code both vertical. Deliberately absent, per spec 4.2: the four-box Discount/MRP/LRP grid, any discount percentage, and the term "LRP". The MRP is no longer struck through - the supplied design labels it instead, and a struck figure directly under a "MRP" heading reads as a correction rather than a comparison. -#} {#- lb_label_data is registered via the `jinja` hook: the barcode is rendered server-side, which the restricted print-format sandbox cannot do itself. -#} {%- set d = lb_label_data(doc.name) -%} {%- set has_saving = d.save_amount and d.save_amount > 0 -%} {#- The readable code is what staff scan the shelf for, so it is sized to fill the label's full height rather than left at a fixed size. 99% of codes are 6-7 characters; the rare 16-18 character supplier barcodes step down so they still fit rather than running off the edge. -#} {%- set clen = (d.code or '')|length -%} {%- set id_pt = 18 if clen <= 6 else (15.5 if clen == 7 else (13 if clen <= 9 else (7.5 if clen <= 12 else 5.5))) -%} {%- set price_txt = "{:,.0f}".format(d.our_price) -%} {#- Prices run to five digits.
